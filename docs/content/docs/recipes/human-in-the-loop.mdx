title: Human in the Loop
description: Pause a workflow for human approval and resume it via an external callback.
---


## Pause for approval

1. Define an idle state and transitions that check the approval decision.
2. Start a durable execution with a stable `eventId` and no approval decision.
3. When the adapter registers a callback, associate its ID with the pending review on your backend.
4. After an authorized user submits a decision, call `SendDurableExecutionCallbackSuccess` to resume the workflow.

## Define the workflow

```typescript
import { OnEvent, Workflow } from 'nestflow-js/core';

enum OrderState {
  PENDING_APPROVAL = 'pending_approval',
  APPROVED = 'approved',
  SHIPPED = 'shipped',
  REJECTED = 'rejected',
  FAILED = 'failed',
}

@Workflow({
  name: 'OrderWorkflow',
  states: {
    finals: [OrderState.SHIPPED, OrderState.REJECTED],
    idles: [OrderState.PENDING_APPROVAL],
    failed: OrderState.FAILED,
  },
  transitions: [
    {
      event: 'order.created',
      from: [OrderState.PENDING_APPROVAL],
      to: OrderState.APPROVED,
      conditions: [(_entity, payload?: { approved: boolean }) => payload?.approved === true],
    },
    {
      event: 'order.created',
      from: [OrderState.PENDING_APPROVAL],
      to: OrderState.REJECTED,
      conditions: [(_entity, payload?: { approved: boolean }) => payload?.approved === false],
    },
    {
      event: 'order.ship',
      from: [OrderState.APPROVED],
      to: OrderState.SHIPPED,
    },
  ],
  entityService: 'entity.order',
})
export class OrderWorkflow {
  @OnEvent('order.created')
  async onCreated() {
    return { reviewedAt: new Date().toISOString() };
  }

  @OnEvent('order.ship')
  async onShip() {
    return { shippedAt: new Date().toISOString() };
  }
}
```

## Start the durable execution

Create the order in `PENDING_APPROVAL` before invoking the Lambda. Use the order ID as `urn` and the producer's stable ID for this event as `eventId`:

```typescript
const startEvent = {
	urn: 'order-1',
	eventId: 'order-created-001',
	initialEvent: 'order.created',
};
```

Reuse `eventId` if you redeliver this event for the same order. With no approval decision, neither guard matches. The orchestrator returns `idle`, and the adapter registers a callback with `ctx.waitForCallback()`.

## Resume with a callback

When your backend accepts a decision, use the callback ID it stored for that review:

```typescript
import { LambdaClient, SendDurableExecutionCallbackSuccessCommand } from '@aws-sdk/client-lambda';

const lambda = new LambdaClient({});

await lambda.send(new SendDurableExecutionCallbackSuccessCommand({
	CallbackId: callbackId,
	Result: JSON.stringify({
		event: 'order.created',
		payload: { approved: true },
	}),
}));
```

Send `approved: false` to reject the order. Send only the `event` name and optional `payload`. The adapter derives a stable `eventId` for the callback event. Approval moves the order to `APPROVED` and the `order.ship` transition takes it to `SHIPPED`. Rejection takes it directly to `REJECTED`.

Set a per-state timeout or a workflow default if the review should expire in less than 24 hours. See [callback timeout configuration](/docs/plugins/durable-lambda#timeout-configuration).
